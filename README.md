# 🎟️ Ticket Zoo — 把你的照片变成专属动物园门票

上传一张照片，选个风格和颜色，马上生成一张独一无二的动物园门票，还能下载成 PNG 保存或打印。

👉 **在线体验**：https://QiuyuanYu.github.io/Ticket-Zoo/

![Ticket Zoo 预览](screenshot.png)

## ✨ 功能

- 📷 上传照片（JPG / PNG / WEBP），本地处理，不上传服务器
- 🎨 实时预览：标题、票价、入场类型、有效期即时更新
- 🦊 三种风格：Cute / Retro / Dream
- 🌈 五套配色，一键切换
- ⬇️ 下载 1500×700 高清 PNG 门票
- 📱 手机、平板、电脑都能用

## 🛠️ 本地运行

直接双击 `index.html` 用浏览器打开即可。

或者用 VS Code 的 Live Server 插件打开。
